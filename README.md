# EL MASRIA — موقع شركة المصرية للسلامة والصحة المهنية

موقع تعريفي **ثابت (static)** لشركة المصرية للسلامة والصحة المهنية: ١٧ صفحة عربية
(RTL) تعرض خدمات الشركة منذ تأسيسها عام ١٩٩٩ — السلامة والصحة المهنية، الحماية
المدنية، الدراسات البيئية، مكافحة الحشرات، أنظمة ISO، العمالة، الإنشاءات، النظافة،
التشجير، العيادة المهنية، والملاعب الرياضية.

**الموقع الحيّ:** <https://elmasria.aidy.site>

---

## نظرة سريعة

| البيان | القيمة |
|---|---|
| النوع | موقع ثابت — **بلا خطوة بناء** (no build step) وبلا حزم أو مدير اعتماديات |
| اللغة | عربي RTL (`<html lang="ar" dir="rtl">`) |
| الصفحات | **١٧** صفحة: ٥ في الجذر + ١٢ تحت `services/` |
| الواجهة | `assets/css/style.css` · `assets/js/main.js` (JavaScript خام، بلا مكتبات) |
| الخطوط | Cairo + IBM Plex Sans Arabic من Google Fonts |
| الأيقونات | ملف sprite واحد `assets/img/icons.svg` يُستدعى بـ`<use>` |
| الاستضافة | `nginx:alpine` داخل صورة Docker يبنيها **Coolify** من فرع `main` |
| الأداء | أصول الشعار محسّنة من ~٨٨٠ KB إلى ~٢٥ KB لكل زائر أول (انظر `BRAND.md`) |

## بنية المستودع

```
.
├── index.html  about.html  contact.html  projects.html  404.html
├── services/                 ← ١٢ صفحة خدمة + index.html
├── assets/
│   ├── css/style.css         ← كل التنسيقات
│   ├── js/main.js            ← القائمة، الكشف عند التمرير، شريط التقدّم
│   └── img/                  ← الشعار والأيقونات والصور
│       ├── icons.svg         ← sprite الأيقونات (مصدر واحد)
│       ├── pack/             ← صور الخدمات
│       └── photos/           ← صور الأقسام (WebP بأحجام متعددة)
├── Dockerfile                ← nginx:alpine + COPY . (نسخ الموقع داخل الصورة)
├── nginx.conf                ← try_files · خريطة تحويلات 301 · رؤوس الأمان
├── .dockerignore             ← ما لا يدخل الصورة (`_tools` و `*.md` …)
├── .gitignore                ← ما لا يُرفع على git (لقطات، أصول مصدر، مسودات)
├── _tools/                   ← أدوات الصيانة والحراس (لا تُنشر على الدومين)
├── BRAND.md                  ← الهوية البصرية: الألوان والخطوط وقواعد التباين
└── COOLIFY-AGENT-GUIDE.md    ← دليل بيئة الخادم (Traefik · Coolify · الفخاخ)
```

> `_tools/` وكل ملفات `*.md` **مستثناة من الصورة** عبر `.dockerignore`، فلا تُنشر على
> الدومين ولا يستطيع أحد تحميلها. الأدوات للسيرفر المحلي فقط.

## التشغيل محليًا

لا يحتاج الموقع أي تثبيت — يكفي أي سيرفر ملفات ثابتة:

```bash
python -m http.server 8080
# ثم افتح http://localhost:8080
```

⚠️ **حدود المعاينة المحلية:** `http.server` لا يطبّق `nginx.conf` — أي تحويلات الـ301
ورؤوس الأمان و`X-Robots-Tag` **لن تعمل** محليًا. لاختبار التحويلات فعليًا استخدم
`_tools/nginx_redirect_test.sh` (يحتاج Docker)، أو اختبرها على النطاق الحيّ.

## سياسة النطاق الواحد (Single-origin policy)

> **القاعدة:** لا يشير أي شيء في المستودع إلا إلى **النطاق المرتبط فعليًا**، وتغييره
> لاحقًا يكون **أمرًا واحدًا** لا بحثًا واستبدالًا في ١٩ ملفًا.

**مصدر الحقيقة الوحيد:** `_tools/site_origin.txt`
(أول سطر غير تعليق وغير فارغ = النطاق).

```bash
python _tools/set_origin.py --check        # حارس: يفشل لو وُجد أي نطاق غريب
python _tools/set_origin.py                # إعادة كتابة المراجع على النطاق الحالي
python _tools/set_origin.py https://new.example.com   # تغيير النطاق ثم إعادة الكتابة
```

**ما يُعاد كتابته** (مراجع *هوية الموقع*):

| الموضع | مثال |
|---|---|
| `canonical` | `<link rel="canonical" href="…">` |
| Open Graph | `og:url` · `og:image` |
| Twitter | `twitter:image` |
| البيانات المنظّمة | `"url"` داخل `application/ld+json` |
| `sitemap.xml` | `<loc>…</loc>` |
| `robots.txt` | سطر `Sitemap:` |

**ما لا يُلمس أبدًا:**

* **النطاقات الخارجية المقصودة** — `wa.me` · `fonts.googleapis.com` ·
  `fonts.gstatic.com` · `schema.org` · `sitemaps.org` · `openstreetmap.org` ·
  `www.w3.org`. الحارس يعرفها ويعدّها «خارجية مقصودة» لا «غريبة».

> **قرار البريد (2026-09-30 · v28):** الموقع **لا يعرض أي بريد إلكتروني** — قناة
> التواصل الرسمية هي **الواتساب** (`wa.me/201000101040`) والهاتف (`tel:`). أُزيل
> `info@elmasria-eg.com` من الشريط العلوي والفوتر وصفحة التواصل والبيانات المنظّمة،
> وتحوّل نموذج التواصل من `mailto:` إلى رسالة واتساب جاهزة. السياسة محروسة بـ
> **`_tools/verify_mail_policy.py`** (يفشل عند أي بريد ظاهر أو `mailto:` أو مرجع
> `#i-mail` أو بقايا الزر القديم). التفاصيل في `BRAND.md` § (8).

**التغطية تلقائية:** الحارس يكتشف الملفات بـ`glob` (`*.html` + `services/*.html` +
`sitemap.xml` + `robots.txt`)، فأي صفحة جديدة تُضاف مستقبلًا **تُغطّى فورًا** بلا تعديل
في الحارس.

## كسر الكاش (`?v=N`)

الملفان `style.css` و`main.js` يحملان إصدارًا في الرابط (`?v=28`) في **١٧ صفحة**،
والصور/الأنماط مُكاشة ٧ أيام. **بعد أي تعديل على CSS أو JS لازم ترفع الإصدار** وإلا
الزائر العائد سيرى النسخة القديمة:

```bash
python _tools/bump_css_version.py --set 29   # حتمي وقابل لإعادة التشغيل
```

> عند تغيير **صورة**، الأفضل تغيير **اسم الملف** لا الإصدار — الكاش يخزّن المسار كاملًا.

## الحراس (Guards)

سبعة حراس يفشلون بـ`exit 1` وبها رسالة واضحة. شغّلهم كلهم قبل أي كوميت يمسّ الواجهة:

```bash
for g in set_origin.py verify_asset_refs.py verify_no_orphan_assets.py \
         verify_icons.py verify_class_coverage.py verify_span_scope.py \
         verify_mail_policy.py; do
  python "_tools/$g"
done
```

| الحارس | ما يمنعه |
|---|---|
| `set_origin.py --check` | أي مرجع لنطاق غير النطاق المرتبط (٩٦ مرجعًا في ١٩ ملفًا) |
| `verify_asset_refs.py` | مرجع لملف غير موجود → صورة مكسورة على الحيّ |
| `verify_no_orphan_assets.py` | ملف تحت `assets/` بلا مرجع (دَين تخزين)، وإعفاء بايت |
| `verify_icons.py` | إيموجي مبعثر، أو رمز أيقونة لا يُحلّ إلى `icons.svg` |
| `verify_class_coverage.py` | كلاس في CSS بلا استخدام في الوسم أو JS |
| `verify_span_scope.py` | قاعدة `span` تتسرّب لأنماط أخرى |
| `verify_mail_policy.py` | أي بريد معروض، أو `mailto:`، أو بقايا النموذج القديم (السياسة: واتساب فقط) |

> **قاعدة ملزمة:** أي حارس جديد لازم **يُثبت أنه يفشل** قبل الاعتماد عليه — احقن الخطأ
> اللي المفروض يمسكه، شغّله، اتأكد إنه فشل برسالة مفهومة، وبعدين رجّع الملف وتأكد إنه
> رجع سليم. الحارس اللي محدش شافه بيفشل = حارس مش موجود.

## النشر

النشر آلي: **Coolify** يبني من فرع `main` بصورة Dockerfile وينشر.

```bash
git push origin main
curl -X POST https://coolify.aidy.site/api/v1/deploy \
  -H "Authorization: Bearer $COOLIFY_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"uuid":"v2qirvm8bovh8uvyuel10fio"}'
```

**التحقق بعد النشر** (لا تعتمد على «النشر خلص»):

* `/` → `200`
* `/index.html` → `301` و`Location: /` **نسبي** (مش `http://`)
* مسار وهمي مثل `/no-such-page` → `404`
* `style.css?v=<الإصدار الحالي>` موجود
* الطلب على `*.aidy.site` يرجّع ترويسة `X-Robots-Tag: noindex, nofollow`

## الاتفاقيات (Conventions)

* **نهايات الأسطر:** صفحات HTML بـ**CRLF**، بينما `sitemap.xml` و`robots.txt` بـ**LF**.
  حافظ على نمط كل ملف كما هو — لا تُوحّدها.
* **الأصول:** أي ملف يُضاف تحت `assets/` **لازم يكون له مرجع**؛ وإلا يمسكه
  `verify_no_orphan_assets.py`. إن كان أصلًا مقصودًا بلا مرجع (مثل master الشعار)،
  أضفه إلى `ALLOW` في الحارس **مع سبب موثّق**.
* **الألوان:** المصدر الوحيد هو `assets/img/logo.png` — أي لون خارج `BRAND.md` ممنوع.
* **الأيقونات:** لا إيموجي في الوسم؛ كل رمز يُضاف إلى `assets/img/icons.svg` ويُستدعى
  بـ`<use href="assets/img/icons.svg#i-…">`.
* **البريد:** الموقع **لا يعرض أي بريد** — قناة التواصل هي الواتساب والهاتف
  (قرار v28، محروس بـ`verify_mail_policy.py`).
* **الوسم مقابل CSS:** لا تُضف كلاسًا في CSS بلا استخدام، ولا تستخدم كلاسًا غير معرّف.
